# LANG

Progress tracker for learning **German** (Goethe A1 → C1) and **Hebrew** (0 → C1, through Arabic), taught by Billy, a Telegram bot ([gemini-telegram-bot](https://github.com/criticalumami/gemini-telegram-bot), private).

**Site:** https://criticalumami.github.io/LANG/

- `data.json` is written every hour by Billy's server (`site_export.py`): progress, weak spots, the syllabus, Billy's lesson material and quiz results.
- `index.html`, `style.css` and `app.js` render it. They use the same monochrome style as [FIT](https://criticalumami.github.io/FIT/).

The courses follow *Basic German: A Grammar and Workbook* and *The Routledge Introductory Course in Modern Hebrew*. Book pages and book text aren't published here.
